# Tracker

Tracker is a habit tracking iOS application built with Swift, UIKit, CoreData, and MVVM.

## Overview
The project is focused on building a production-style tracker app with persistent storage, clear screen flows, and maintainable architecture.
It is designed to practice app structure, state handling, and user interaction in a real mobile product.

## Features
- habit tracking
- persistent local storage
- CoreData integration
- screen flow and navigation
- clean UI built with UIKit
- MVVM-based structure

## Tech Stack
- Swift
- UIKit
- CoreData
- MVVM
- iOS app architecture
- state management
- Git

## Goals
- build a complete mobile tracker app
- practice persistence and app structure
- improve UIKit and architecture skills
- strengthen readiness for junior iOS developer role
